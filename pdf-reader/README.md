# PDF Reader

A standalone tool that reads any PDF aloud in a natural voice. It is a single
self-contained web page — no install, no server, no accounts, and nothing ever
leaves your computer.

## How to use it

1. Open **`index.html`** in your browser (double-click it, or drag it onto a
   browser window). Chrome, Edge, or Safari work best.
2. Choose a PDF (click the box or drag a file onto it).
3. Pick a voice, set the speed, and press **Play**.

The current sentence is highlighted as it reads; click any sentence to jump
there.

### Notes

- **Voices** come from your device/operating system. Modern Mac, Windows, iOS,
  and Android have very natural-sounding voices; some are marked "online" (higher
  quality, needs an internet connection). If one sounds robotic, try another in
  the Voice menu.
- **Scanned PDFs** (pages that are just images, with no real text) can't be read
  aloud — there's no text to extract. The page will tell you if that's the case.

## Rebuilding

`index.html` is generated by baking the [pdf.js](https://mozilla.github.io/pdf.js/)
library and worker into `template.html` as base64, so the page has zero external
dependencies. To rebuild after editing `template.html`:

```bash
node build.mjs
```

The pdf.js files are vendored under `vendor/`, so the build works from a clean
checkout with no `npm install`.
